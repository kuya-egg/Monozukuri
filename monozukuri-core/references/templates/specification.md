# Specification template

Copy the block below to `.monozukuri/specifications/NNNN-title.md` and fill it
in.

```markdown
# Spec NNNN: <title>

- Status: draft | agreed | superseded
- Date: YYYY-MM-DD
- Author: <name/role>

## Problem
<what is wrong or missing now, and why it matters>

## Goals
<the outcomes this change must achieve>

## Non-goals
<explicitly out of scope, to bound the work>

## Constraints
<technical, product, time, or compatibility limits that shape the solution>

## Proposed approach
<the design chosen, at enough detail to build and review against>

## Alternatives
1. <alternative> — <why not chosen>
2. <alternative> — <why not chosen>

## Risks
<failure modes, unknowns, and security or data boundaries to watch>

## Definition of Done reference
<which Definition of Done applies (task type), plus any spec-specific
acceptance checks>
```
